# MN FGC Hub

A landing page for the Minnesota fighting game community: Mixfest up top, local orgs below.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Logos

Drop org logos into `public/logos/` using the filenames in `lib/communities.ts` (for example `rtm_logo.png`). Cards show initials until a matching file is there.
